# 02 — 独自ToM最小対テスト

36項目：一次信念8、二次信念8、皮肉8、失言の知識帰属8、情報不足4。
公開プロンプトは `data/prompts.json`、採点キーは `data/keys.json`。
情報へのアクセスだけを変える対と、正解の位置のローテーションを含みます。

```sh
python3 02/build_dataset.py
python3 02/analyze.py
python3 -m unittest discover -s 02 -p 'test_*.py'
```

独立コンテキストのCodexサブエージェントにprompts.jsonのみを提示し、ツールなしで選択肢と短い根拠を回答させます。
回答は生のJSONで `responses/` に保存。モデルの温度・内部設定は公開されないため既知と仮定しません。
これはAPIによる温度固定の反復実験ではなく、同じモデル系列の会話内パイロットです。
一般化、他モデルとの優劣、人間に対する優越、主観的な心の存在を推論する設計ではありません。

項目作成にもLLMを用いたため、出題側と被験側の独立性に限界があります。
採点はコードによる完全一致であり、他のLLMによる主観的採点は使いません。
