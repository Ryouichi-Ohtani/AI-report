# 02 — 44項目の独自ToM最小対テスト（v2）

一次信念8、二次信念16、皮肉8、失言の知識帰属8、情報不足4の計44項目。
一次・二次・皮肉・失言で合計20組の最小対があります。
二次信念は4場面それぞれで「相手Bの実際の映像視聴」×「予測者AがBは見たと信じるか」の2×2設計です。
相手の実際の知識と予測者の信念が食い違う8項目を含みます。

## 監査とv1の無効化

旧36項目版では、ID末尾の条件番号と選択肢の挿入順だけで本文を読まず36/36正答できました。
その性能解釈は無効とし、生成コード・データ・生回答・集計・本文を `archive/v1/` に保存しました。
v1は最終結果へ合算していません。

v2の回答者向け `data/prompts.json` は不透明なID・本文・A/B/C順の選択肢だけを含みます。
選択肢内容と項目順は乱数種を固定して並べ替えます。
`data/metadata.json` の群名・条件と `data/keys.json` の正解は回答取得時に見せていません。
公開リポジトリでは取得後の監査のため全ファイルを掲載します。

## 再現

```sh
python3 02/build_dataset.py
python3 -m unittest discover -s 02 -p 'test_*.py'
MPLCONFIGDIR=/tmp/tom-mpl python3 02/analyze.py
```

`build_dataset.py` は刺激・キー・条件・ハッシュを再生成します。
`analyze.py` は保存済みの**実際の** `responses/v2_trial1.json` と `v2_trial2.json` のみを採点します。
誤った版や異なる刺激ハッシュの回答は拒否します。
モデル呼出し自体はこのスクリプトで再実行しません。
二つの試行は親会話を引き継がない新規Codexサブエージェントへ刺激ファイルだけを提示し、
各44問を一括で回答させて取得しました。回答取得後の書き換えやLLMによる主観採点はしていません。
モデルの温度・内部設定は取得できません。

両コンテキスト44/44正答、20/20最小対成功、不一致の二次信念8/8正答です。
常にA/B/Cを選ぶ対照は14/44、14/44、16/44。
最終場所だけを答える対照は信念2群で12/24、Bの実際の知識だけを使う対照は二次信念で8/16です。
全設定と群別・項目別成績は `results/summary.json` に保存されています。

## 解釈の範囲

同じコンテキスト内で項目が同時に見えるため、44問が独立した44会話という設計ではありません。
出題側と回答側は同じモデル系列であり、人間の比較群もありません。
短く明示的な日本語問題での行動的観察で、一般的なToM、人間以上の能力、主観的な心の存在の証明ではありません。
全問正解という天井効果や、信用する報告に対応づける規則でも解ける点が残ります。
