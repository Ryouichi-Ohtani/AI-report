# 03 — 進化計算を弁当で説明し、形状設計の応用へつなぐ

8種類の食材から16区画の弁当を作る、著者定義の教育用モデルです。
栄養値・価格はすべて架空の係数であり、実際の食品データや健康上の推奨ではありません。

```sh
MPLCONFIGDIR=.cache/matplotlib python3 03/bento_ga.py
python3 -m unittest discover -s 03 -p 'test_*.py'
```

人口48・60世代・10乱数種で、GA、突然変異なし、無作為探索を同じ2928評価で比較します。
245157通りの食材個数ベクトルを全列挙して最適値も確認します。
位置の違いは評価しないため、遺伝子配列と個数ベクトルは一対一ではありません。
図はすべてプログラムから作成したオリジナルのベクター図です。
Xenobotの概念図は論文の実験を再現したシミュレータでも実測画像でもありません。

応用の一次資料：Kriegman et al. (2021), https://doi.org/10.1073/pnas.2112672118
