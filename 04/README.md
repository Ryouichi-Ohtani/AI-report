# 第4問: 小町算で √2 を近似する

Python 3.9+、NumPy、Matplotlib を使います。ルートから:

```sh
python3 -m unittest discover -s 04 -v
MPLCONFIGDIR=/tmp/komachi-mpl python3 04/run_experiments.py
```

`solver.py` が厳密有理数と共通探索グラフを定義し、`run_experiments.py` が
実験・JSON/CSV・論文用PDF図を再生成します。乱数は使用しません。
測定時間は実行環境に依存します。`results/results.json` に環境と全設定があります。

## 文法と比較条件

- 数字を左から一度ずつ使う。連続数字の連結、小数点1個、1桁数字への階乗を許可。
- 二項演算は `+ - * /`、途中結果の絶対値上限は `10^9`、分母は80 bit以下。
- 全方式で同じ後継順序・重複判定・ノード予算。予算到達を「解なし」とは扱わない。
- A* は `g + h` が主キー。`h = k+1`（未使用数字あり）、`max(0,k-1)`（なし）で、
  `k` はRPNスタック長。全残余数字を1個の連結葉として追加できる緩和による許容的下界。
- `astar_guided` は主キーが同じ場合だけ、単一演算後の近さで整列。
  その近さ自体を許容的ヒューリスティックとは呼ばない。
- `generated` はフロンティアへの登録回数、`expanded` は後継生成した状態数。
  `peak_frontier` にclosed集合を含めないため、全メモリ使用量とは異なる。

## 高精度探索

区間DPで4桁・5桁の式の有理数辞書を構築し、根の演算を逆算して隣接候補を調べます。
同値の式は演算子数・文字数が小さい表現を保存します。
最後の誤差は Decimal 60桁で検証します。
固定分割4|5と5|4を調べる追加実験であり、全9桁文法の大域最適性は主張しません。
探索のDFS/BFS/A*比較にDPの前計算を流用していません。

課題ページには √2 の冒頭の桁と、並べ替え例1の表示値に誤植があるため、
元の式そのものから計算し直した値をJSONに保存しています。
